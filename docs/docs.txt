system design overview
	data collection: from kaggle
	data preprocessing: data augmentation
	model training: transfer learning on pretrained model efficientNetB0
	model evaluation: accuracy, classification report(precision, recall, f1 score), confusion matrix
	prediction: capture image from webcam

------------------------------------------------------------------------------------------------------------------------------------------

data collection: 
	from Kaggle:
	balanced dataset: 2994 images for each categories: mask_weared_incorrect, with_mask, without_mask
data preprocessing:
	data augmentation: created variants of image based on transformation like flipping, rotation, zooming, brightness and contrast.
	dataset splitting: splitted the data into 70% train, 15% validation and 15% test set 
	reshaping: images reshaped to resolution of (batch_size*224*224*3) for compatibility with efficientNetB0 input expectation
model architecture:
	..................
model training: 
	transfer learning on pretrained model efficientNetB0
	optimizer: Adam, chosen for its adaptive learning rate and convergence stability
	batch size: 64
	loss function: sparse_categorical_crossentropy
	epochs: 50 specified but early stopped at 20, early stopped based on validation accuracy
model evaluation: 
	efficientV2B0 vs efficientB0 model
		accuracy: training:98.79%, testing:98.43%
		classification report
		confusion matrix 
	=> efficientnetB0 selected
prediction:
	reshaping: reshaped captured image to shape (1*224*224*3) for compatibility with efficientNetB0 input expectation
